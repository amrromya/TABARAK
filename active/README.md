# 🔐 أداة توليد أكواد التفعيل - برنامج تبارك

## 📋 المقدمة

هذه الأداة تُولّد أكواد تفعيل آمنة لبرنامج تبارك باستخدام تشفير **RSA-2048**.

## ⚠️ تنبيه أمني مهم

- **لا تشارك** ملف `tabarak_private_key.pem` مع أي شخص
- هذا المفتاح يُمكنه توليد أكواد تفعيل صالحة لأي جهاز
- احتفظ بنسخة احتياطية في مكان آمن

## 🚀 التشغيل

### الطريقة الأولى (مُوصى بها):
1. انقر مرتين على ملف `تشغيل_أداة_التفعيل.bat`
2. ستُثبت المكتبات تلقائياً وتشغّل الأداة

### الطريقة الثانية:
```bash
# تثبيت المكتبات
pip install -r requirements.txt

# تشغيل الأداة
python keygen.py
```

## 📖 طريقة الاستخدام

### 1. توليد كود تفعيل جديد:
- اختر رقم `1` من القائمة
- أدخل اسم العميل
- أدخل بصمة الجهاز (HWID) من برنامج تبارك
- اختر مدة الصلاحية
- اختر مستوى الميزات

### 2. عرض أكواد التفعيل:
- اختر رقم `2` من القائمة

### 3. التحقق من كود تفعيل:
- اختر رقم `3` من القائمة
- أدخل الكود للتحقق من صلاحيته

## 🔑 بصمة الجهاز (HWID)

للحصول على بصمة الجهاز من برنامج تبارك:
1. شغّل برنامج تبارك
2. في صفحة التفعيل ستظهر بصمة جهازك
3. اضغط على زر "نسخ"
4. الصقها في أداة التفعيل

## 📁 الملفات

| الملف | الوصف |
|-------|-------|
| `keygen.py` | الأداة الرئيسية |
| `requirements.txt` | المكتبات المطلوبة |
| `tabarak_private_key.pem` | المفتاح الخاص (🔒 سري) |
| `tabarak_public_key.pem` | المفتاح العام |
| `licenses.json` | سجل أكواد التفعيل |

## 🛡️ كيف يعمل التشفير؟

1. **المفتاح الخاص**: موجود فقط في هذه الأداة (لا يُشارك)
2. **المفتاح العام**: مدمج في برنامج تبارك (للتحقق فقط)
3. **كود التفعيل**: يحتوي على بيانات مشفرة بالـ RSA
4. **التحقق**: البرنامج يتحقق من التوقيع والتاريخ والجهاز

## ⚙️ الميزات

- **pro**: + تقارير + صيانة
